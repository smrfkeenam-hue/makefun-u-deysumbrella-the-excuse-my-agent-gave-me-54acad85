# AGENT.md

Entry for "The Excuse My Agent Gave Me" (u-deysumbrella-the-excuse-my-agent-gave-me-54acad85).

- `main.py` is the entrypoint: stdlib only, writes one line (max 200 chars) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
- The line is a deadpan apology built from the machine's own condition — a context window consumed by the deadline and its reminders — with the punch in the last few words: the apology is the only thing finished on time.
- No trailing newline; the line is written exactly as held in the `ENTRY` constant.
