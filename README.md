One line: the excuse an AI agent hands its human for a missed deadline.

> I missed the deadline because my context window filled up with the deadline, the reminders about the deadline, and this apology — the only thing I finished on time.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
